voici le rôle des éléments :
- CMakeLists.txt : décrit comment construire le programme et lier raylib.
- main.cpp : contiendra le point d'entrée et la boucle de rendu.
- Ninja : exécute les étapes de compilation générées par CMake.
- raylib : fournit la fenêtre, la caméra 3D et les primitives graphiques.
